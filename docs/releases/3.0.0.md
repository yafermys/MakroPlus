# Makro+ 3.0.0 - Rewritten in Rust, now on Windows and Linux

Makro+ 3 is a complete rewrite in Rust: one small native executable, no .NET,
lower memory use, and the same settings format. Your 2.x shortcuts are imported
automatically on first start; the old settings file is left unchanged.

## What's new

- **One shortcut, several apps.** Workflows can bring any registered app to the
  front (starting it if needed), copy the selection, paste, save, wait for a
  window, copy or move files and pass values between steps with variables such
  as `{selection}`, `{clipboard}`, `{ai}`, `{date}` and `{last_file}`.
- **Inside apps.** Scan an open app to list its menu commands, buttons, tabs and
  fields with their keyboard shortcuts, then assign any of them to a key. Steps
  can run menu commands, click elements, fill and read fields (Windows).
- **Clipboard page.** Everything you copy is listed, searchable and pinnable.
  Edit an item, copy it back, transform it with AI, or turn it into a shortcut
  that pastes it. Content marked private by password managers is not stored.
- **AI that does more.** 46 step types, up to 200 steps per plan, two
  validation rounds, scanned in-app commands as context, and AI steps that run
  when the shortcut runs (translate, fix, summarise, rewrite).
- **Touchpad shapes are back** and live in the same editor: pick *Key / mouse
  button* or *Touchpad shape* as the trigger type.
- **Switch keys off.** Disable a key's function everywhere or in one app,
  without deleting anything; untick it to restore the key.
- **Shortcut guide you configure.** Hold Right Ctrl to see the shortcuts of the
  app in front; choose whether it lists app-specific, global, all-app, the app's
  own or Windows system shortcuts, and optionally switch off the guide key's
  normal function.
- **Themes.** 16 presets, themes built from scratch, and a background image,
  animated GIF or video, with a theme generated automatically from its colours.
- **Window.** No system title strip: maximised and full-screen (F11) windows use
  the whole screen. Shortcuts run immediately from the app with *Run now*.
- **Optional install.** *Settings › Install* (or `Install.cmd`) adds Makro+ to
  Start and to *Settings › Apps › Installed apps* with an uninstaller. The exe
  still runs portable; `portable.txt` keeps data next to it.
- **Updates.** Makro+ checks for a newer release on every start (can be turned
  off). Nothing is downloaded or installed automatically.
- **Linux (x86_64).** `.deb`, `.rpm`, AppImage and `.tar.gz` packages. Global
  shortcuts work on X11 and Wayland through evdev/uinput.

## Linux notes

Makro+ reads input devices and creates a virtual input device, so your user must
be in the `input` group (`sudo usermod -aG input "$USER"`, then log in again).
The `.deb`/`.rpm` install the udev rule; for the AppImage/tarball see
`README.txt`. On Linux, keys are swallowed and can be switched off only in
*Exclusive mode*; app-specific shortcuts need X11, Sway or Hyprland; scanning
controls inside apps is Windows-only; text typing uses `wtype`/`xdotool` when
installed and video backgrounds need `ffmpeg`.

## Validation

- Unit tests: key capture (including modifiers released before the key),
  shortcut matching, two-key chords, switched-off keys, shape recognition, AI
  plan parsing for multi-app workflows, version comparison and lossless import of
  2.x settings.
- End-to-end test with the real Windows hooks and `SendInput`: modifier + key,
  two-key chord, modifier + wheel and a switched-off key.
- CI builds and tests on Windows and Linux and produces the Linux packages.

Public screenshots use synthetic data. No language model weights are included.
Source code is **GPL-3.0-only**; runtime components and models keep their own
licenses. The 2.x C# source remains in `src/`; 3.0 is in `rust/`.
