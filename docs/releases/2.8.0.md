# Makro+ 2.8.0 - Application shortcuts and release notifications

Search for an application and see its readable in-app key assignments alongside
your Makro+ shortcuts. The new **Application shortcuts** page supports app-name,
action and key search, source filters, and optional global/disabled entries.

## What's new

- Learn when a newer stable Makro+ version is published: a tray notification and
  in-app banner link to its release. Settings includes manual checking and an
  automatic-check opt-out. Successful checks are cached for six hours, failures
  retry later, and a version is announced once across restarts. No automatic
  download or installation; only public release metadata is requested.
- Detect Brave's own saved browser shortcuts, customized accelerators, removed
  assignments and extension commands.
- Read supported VS Code-family editors (including Antigravity), Notepad++,
  Sublime Text and JetBrains custom keymaps.
- Read supported VLC, OBS, PowerToys Keyboard Manager, Minecraft, League of
  Legends and Counter-Strike 2 settings.
- Inspect shortcut hints exposed through native menus of open Windows apps.
- Keep Makro+ launch/scoped assignments together with the app they affect.
- Show documented Spotify/Discord defaults as **Reference only** entries.
- Display coverage information rather than treating unreadable settings as
  proof that an app has no shortcuts.
- Preserve original settings with read-only new providers. Existing supported
  Windows shortcut and editor JSONC source editors remain available.
- Improve indexing and draft conflict checks, with explicit limits for dense
  conflict sets and malformed/oversized sources.

Scanning runs in the background. Searching filters its results without reading
the disk again on each keystroke. The scan does not launch apps, send their keys
or register their shortcuts again. Private/cloud settings, inherited defaults,
custom-drawn menus and physical scancodes can limit coverage.

## Start here

Download **MakroPlus-2.8.0-win-x64.zip**, extract the entire archive and open
**MakroPlus.exe**. Close an older running copy first. Use **Install.cmd** for a
per-user installation. Open **Application shortcuts**, choose **Scan applications**
and search for an app. Select a row for its context and source details.

The package includes **USER_GUIDE.html**, **APPLICATION_SHORTCUTS.md**, the runtime,
licenses, test summary and a SHA-256 manifest. Requirements remain Windows 10/11
x64 and .NET Framework 4.8. The build is unsigned; verify the ZIP using its matching
`.sha256` file.

**No language model weights are included or downloaded automatically.** Put your
own supported GGUF into `models`, or configure a compatible API server. The
[recommended optional Qwen model](https://github.com/yafermys/MakroPlus/blob/v2.8.0/docs/RECOMMENDED_MODEL.md)
and other supported models remain selectable. Scanning and saved shortcuts do not
need a model request.

## Validation

- 745 existing desktop checks.
- 64 application-reader/search/filter checks, including 57 headless checks.
- 117 interface/system-action checks, including the 102 headless system subset.
- 14 headless persistence checks.
- 72 release-notification checks, including 64 headless fake-network checks.
- Clean source archive compilation and byte/content verification.
- ZIP-entry hashes, executable/package versions, prerequisites and model exclusion.
- Windows CI builds and runs the headless checks without sending desktop input.

Public screenshots use synthetic data. Real machine-scan results, private settings
and model weights are excluded from the repository and release package.

See [supported applications and coverage](https://github.com/yafermys/MakroPlus/blob/v2.8.0/docs/APPLICATION_SHORTCUTS.md)
for details. Source code is **GPL-3.0-only**; runtime components and models retain
their own licenses.
