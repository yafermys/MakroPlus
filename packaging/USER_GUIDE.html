Your inputs, your shortcuts

Use keyboard keys, mouse buttons, wheel directions and touchpad shapes to launch applications, open content, send keys or run a sequence of actions. This guide opens locally without an internet connection. Your browser's Find command searches the guide; Print can save it as a PDF.

1. Install and first launch

  1. Extract the entire ZIP into a folder. Keep MakroPlus.exe, runtime, models and the help files together. Run the extracted executable.
  2. For a per-user installation and desktop/Start menu shortcuts, run Install.cmd. Windows 10/11 x64 and .NET Framework 4.8 are required. The installer checks the Visual C++ runtime.
  3. Use Home to create a prompt shortcut, create a direct assignment or record a macro. The left sidebar separates INPUTS, WORKSPACE and TOOLS & SETTINGS.
  4. Basic direct assignments and saved plans work without a language model. Configure a model only to generate new plans from prompts.

To reopen this guide, use Settings → Open user guide, or open USER_GUIDE.html in the extracted/installed folder.

2. Download and set up a model

Local GGUF model

  1. Download a chat/instruction model in GGUF format. Choose an architecture supported by the bundled llama.cpp runtime and a model that fits your available memory. Extract it if it came in an archive; renaming another format to .gguf does not convert it.
  2. Open AI model → Configure model → Open models folder. Copy your downloaded .gguf into this folder. The Makro+ ZIP contains only folder instructions, not model weights.
  3. Choose Local GGUF file. If no previous file was selected, a single GGUF in models is detected automatically. Click Refresh models folder if you copied the file while the settings dialog was open.
  4. For several models, click Browse GGUF… and choose the one you want. You may also browse to a model in another directory. Save model settings.
  5. Generate a prompt preview. The first request loads the model; later requests reuse the loaded session. If GPU startup fails, the app tries the same model on CPU. CPU inference may take longer.

Compatible API server

  1. Select Compatible API server.
  2. Enter the server's OpenAI-compatible chat-completions base URL, for example http://localhost:1234/v1/. A full /chat/completions URL is also accepted. Enter the exact model ID exposed by that server.
  3. Enter an API key if required and save. Prompts and registered application context are sent to that chosen server. API keys are encrypted for the current Windows user and omitted from exported settings.

3. Add applications, including closed apps

An application does not need to be open to create or save its shortcuts. You need its installed executable path.

  1. Open Applications and add an application.
  2. Use Choose .exe files to select installed applications even when closed. You can select several files. Running applications are offered as another convenient source.
  3. Confirm the selected files. Adding an application does not launch it. Registered apps stay available when closed.
  4. Choose the registered application when creating a direct assignment or select it as the destination in a prompt. You can also use the prompt editor's Target .exe picker.
SelectionMeaning
Global scopeThe shortcut can activate in any application. Use this to launch a closed application or open a URL from anywhere.
Application-specific scopeCreate it while the application is closed if you want. At runtime it activates when that application is in the foreground.
Target applicationThe app that should receive an open/resource operation. It is independent of the activation scope.

Sending keys, clicking visible controls and recording an existing screen require a target window when those operations actually run. To work with a closed app, request opening it first, then focusing it, then performing the UI actions. Creating and previewing that plan does not require the app to be running.

4. Create a keyboard or mouse shortcut

  1. Choose a new direct assignment from Home or the shortcut list.
  2. Give it a name, choose its profile, then capture the trigger using Capture keyboard / mouse. You can select a mouse button or wheel direction from the list. Escape cancels capture.
  3. For Del + 5, hold Delete, press 5, then release. It is a two-key trigger, not the numeric subtraction key.
  4. Choose Global or Application-specific scope. For an application scope, select a registered app or its .exe; it can be closed.
  5. Choose the action type and fill its fields. For Application, select its executable and optional startup arguments. For Send key, capture the combination to send.
  6. Review conflict messages, enable the assignment and save. The action runs after all trigger keys are released.

Keyboard shortcuts lists keyboard-triggered assignments; Mouse shortcuts lists mouse-triggered assignments. Edit existing entries to change their trigger, action, profile or enabled state. “Also send the main key to the source application” lets the original main key through where supported.

5. Write a prompt and review its plan

  1. Choose Create a prompt shortcut or the equivalent prompt action. Configure your model through Change model if needed.
  2. Write the command in English. Specify what should happen, the target application if relevant, and the activation key. Alternatively, choose the trigger in Trigger, target app & advanced options.
  3. Set the activation scope and destination separately. Registered closed apps are valid selections. Use Global for launch shortcuts that should work from anywhere.
  4. Click Generate preview. You can cancel generation using the same button. The model creates a plan; previewing does not run its steps.
  5. If a question appears, supply the missing information and regenerate. When the plan is ready, inspect the target application, trigger, exact text, waits, order and any scripts.
  6. Save the assignment. Triggering it later executes the saved plan directly; it does not ask the model again.
Tips for clear prompts
  • Use explicit actions: open, type, wait, press, select all, copy.
  • Put literal text in double quotes, and specify waits with units, for example wait 500 ms.
  • Use “selected text” for the current selection. Use “select all text and copy it” only when you want everything selected.
  • Use exact URLs, paths or application names. For duplicate app names, choose the exact executable in Target application.
  • Use “then” to make action order clear. Include “open the application first” when later UI actions need a window.
  • For a touchpad shape, describe only the action; the recorded shape already supplies the trigger.

The advanced rule interpreter provides a model-free option for its supported key/text/wait commands. Unrecognized requests need the model or manual editing. The model uses your prompt and registered app information; it does not see the application's current screen. Its plan still needs your review.

7. Touchpad shapes and prompt actions

  1. Open Touchpad gestures. Leave Continuously recognize touchpad shapes enabled.
  2. Windows Precision Touchpad is the default source. For a legacy device, use Detect my touchpad and move only your touchpad, or switch back with Use Windows Precision Touchpad.
  3. Choose Add a shape or Create with prompt. Name the shape, choose its profile and record a distinct one-finger path after the recording delay.
  4. For a prompt action, click Describe action with prompt. Enter only what should happen, review the model plan, choose Use this action, then Save shape shortcut. You can instead select an existing action or use Create / edit action.
  5. Switch to your target application. Draw the saved shape and pause. No hotkey, mouse button or activation tap is required.

Pause to finish controls how long the recognizer waits after movement (default 600 ms). Match confidence controls how close the path must be: raise it to reduce accidental matches. Edit a shape to re-record its path or change its action, scope, profile and enabled state.

Recognition is suspended inside Makro+, while editing/recording, with held keys/buttons, during another workflow and when paused. Similar or uncertain shapes do not execute. This recognizes one-finger pointer paths, rather than replacing Windows multi-finger gestures. Device support depends on the raw input exposed by its driver.

8. Record and edit macros

  1. Choose Record macro. Start recording, switch to the target window and perform the actions. The target window must be available for actual screen/input recording.
  2. Press F10 to stop. Review recorded focus, key, text, wait, click, drag and scroll steps.
  3. Edit, add, duplicate, remove or reorder steps as needed. Configure the trigger, scope and profile, then save.

Accessible controls are preferred for suitable clicks. Other mouse steps use window-relative coordinates. You can edit button, position, drag endpoint, duration, modifiers and scrolling details. Optional proportional positioning can adapt positions when resizing; otherwise restore the recorded window size. A covered point or unexpected foreground change stops the sequence. Add an Open application step before Focus if the macro must launch a closed app first.

9. Profiles and application preferences

Profiles groups shortcuts for different activities. Select the active profile in the main window. “All profiles” assignments remain shared; matching assignments in the active profile take precedence. Switching profile cancels pending input.

Preferences stores default browser/media destinations and app matching rules, such as opening Spotify links in Spotify. Explicit choices in a prompt take precedence over defaults. Check learned preferences if links consistently open in an unexpected app.

10. Conflicts and detected computer shortcuts

The Conflicts view compares trigger, application scope and profile. A duplicate in the same effective scope is a conflict. A specific application/profile overriding a shared assignment is a priority relationship; inspect the warning before saving.

The computer-shortcut tools detect supported Windows .lnk hotkeys and supported VS Code-compatible keybinding files. Add scan locations, refresh, then edit supported source entries. Backups of changed sources use .akilli-kisayol.bak. Some known defaults are informational; use a personal remap when the original source cannot be edited. Source filters distinguish personal assignments, detected shortcuts and known defaults.

The system probe can check registration conflicts for suitable keyboard combinations. Prefix/two-key triggers and many shortcuts handled internally by other apps cannot be fully probed. Windows has no single source listing every application's internal shortcuts.

11. Themes and custom palettes

Open Appearance or Settings → Customize appearance. Choose Graphite, Midnight or Forest for dark palettes, or Paper, Mist or Sand for light palettes. Coral and peach are secondary accents.

  1. Select a starting theme and choose Create theme.
  2. Name it, choose its light/dark classification and edit the colors using the color picker or #RRGGBB fields. Preview updates while editing.
  3. Choose Save and apply. Custom themes can be edited or deleted later.
  4. Use Export selected to share a palette-only .makrotheme.json; use Import theme to add a shared palette.

Theme files contain palette data rather than your shortcuts, API keys or model settings.

13. History, tray and cancellation

History is saved in coalesced background disk writes. Settings changes still save synchronously. If a history save fails, the latest state remains pending for retry on another action or clean exit. A final close save may take longer on a slow or unavailable disk; a forced process kill can lose unsaved history.

History records recent execution requests, completion messages and errors. A sent request means the action was dispatched; it does not prove that a web page loaded, media started or an external application finished processing.

Minimize to keep Makro+ available in the tray. Use Pause/resume to suspend shortcuts; the tray also controls continuous touchpad recognition. Closing the application stops its input engine. Press Escape to cancel remaining steps in a running sequence; steps already sent cannot be undone. While creating a model plan, use the generation button to cancel.

14. Backup, transfer and updates

Settings are stored at %LOCALAPPDATA%\AkilliKisayol\settings.json, with a previous-version .bak. Use Transfer and diagnostics to export/import shortcuts, profiles, shapes, custom themes and preferences. API keys are omitted from exports; enter them again on the destination computer.

On another computer, match application paths during import, rescan external shortcuts and recalibrate a legacy touchpad source if needed. Keep your own copy of downloaded model weights; exports and the distributed ZIP do not contain them.

For updates, close the installed app before running the new installer. The package's models folder contains only README instructions; existing model files are retained when that directory is merged during an update. For portable use, keep the complete app and its models together. Back up personal models before deleting or uninstalling the app directory.

15. Troubleshooting

SymptomCheck
No model foundUse Open models folder; copy an actual GGUF there and refresh. Choose a file explicitly if several exist or a previously selected path is missing.
Unsupported model / load failureConfirm GGUF format, architecture support and available memory. Try CPU by disabling GPU in the prompt's advanced settings, or choose a compatible API server.
Slow first promptThe model is loading. Later requests reuse its session. Fast planning, a smaller suitable model and concise requests can reduce planning time. Saved shortcuts do not invoke the model.
Model output is incompleteIncrease Maximum output tokens or try Fast planning. Select a chat/instruction model that follows JSON instructions.
HTTP errorCheck base URL, model ID and credentials. Confirm the server supports chat/completions. Unsupported request parameters are adapted on explicit capability errors; structured output can also be disabled.
“Which trigger key?”Add an activation phrase such as “when I press F8”, or set the Trigger field. In a shape's action prompt, the recorded shape supplies the trigger.
Wrong applicationCheck Global/application scope, Target application and Preferences. Register or select the exact executable, especially with duplicate names. It can be closed while you create the assignment.
Shortcut does not activateEnable it, resume the engine, activate its profile and release all keys. Application-specific assignments need their scope app in front at runtime. Check Conflicts and reserved combinations.
Key/click action fails in a closed appUse a Global plan that opens the application first, then focuses it before the UI actions. A Send key assignment sends to the foreground window.
Mouse point or macro target changedRestore the window/size, uncover the target, or re-record/edit the relevant step. Escape cancels remaining steps.
Touchpad shape does not runSwitch out of Makro+, release held keys/buttons, enable recognition and check profile/scope. Recalibrate legacy devices, use a more distinct path and review confidence/pause settings.
Vendor key / Fn does not captureConfigure the device utility to expose a standard Windows key or mouse button. Enable software-remapped input if that utility injects ordinary events. Driver-only signals may not be available.
Model reports success but nothing happenedPreview generation does not execute actions. Save, then trigger the shortcut. Inspect History; model wording does not verify external app results.
