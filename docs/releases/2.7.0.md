# Makro+ 2.7.0 — Simpler interface and Windows actions

Create shortcuts more easily, use the interface in **English or Türkçe**, and control Windows directly from a key combination, mouse input or touchpad shape.

## What's new

- A simpler Home, clearer navigation and an editor that groups advanced scope/profile options together.
- A saved English/Türkçe language selector in the sidebar.
- **Recommended shortcuts:** 16 ready-to-customize actions for screenshots, clipboard history, window navigation, settings and more. Choose your own input; existing conflict checks still apply.
- **System actions:** lock your session, open Windows tools/settings, search for updates, request shutdown/restart, or close visible application windows.
- Native system actions in prompt-generated plans and editable macro steps, without requiring a registered or running app.
- Updated offline instructions and a shorter GitHub landing page. Existing macros, themes, profiles, application routing and model choices remain available.

Shutdown, restart and closing open applications ask for confirmation **when triggered**. Close requests respect save dialogs and permissions, preserve Makro+ and the Windows shell, and do not force-kill background processes. Windows Update checks search only; they do not download or install updates and may take several minutes.

## Download and start

Download **MakroPlus-2.7.0-win-x64.zip**, extract the entire archive, then open **MakroPlus.exe**. Use **Install.cmd** for per-user installation. Choose your language and open **Add shortcut** or **Recommended shortcuts**.

Requirements: Windows 10/11 x64 and .NET Framework 4.8. The Windows package includes the runtime, prerequisite installer, licenses, offline guide and a `models` folder with instructions. The build is unsigned. Verify the ZIP using its matching `.sha256` file.

## Optional model setup

**No language model weights are included or automatically downloaded.** Copy your own supported GGUF into `models` next to MakroPlus.exe, then choose it in **AI model → Configure model**. Compatible chat-completions API servers are also supported.

Recommended tested starting point: **[Qwen3.5-4B Q4_0 GGUF](https://github.com/yafermys/MakroPlus/blob/v2.7.0/docs/RECOMMENDED_MODEL.md)**. Other supported models remain selectable. Saved shortcuts execute directly, without another model request.

Example prompt: `When I press Ctrl+Alt+F6, check Windows updates.` Review the generated plan before saving; this example is not an automatically installed hotkey.

## Validation

- 745 existing desktop checks.
- 117 interface/system-action checks, including input conflicts, cancellation, language switching, system steps and touchpad assignments.
- 102 headless system-dispatch checks and 14 headless persistence checks; Windows CI runs these without desktop input.
- Four real Qwen prompt-planning cases, with no resulting actions executed.
- A real online Windows Update search, without downloads or installation.
- Normal native close/cancel behavior verified only on a controlled test window. Actual shutdown, restart and lock were not performed on the development computer; their fixed commands and confirmation paths were checked with a fake host.
- Package verification checks every ZIP entry, file hashes, executable version, prerequisites and model exclusion.

The 102 headless system checks are a subset of the 117 interface/system checks. Device-specific keys and touchpad behavior still depend on Windows and the driver.

Source code is **GPL-3.0-only**. The matching source ZIP contains the buildable source for this version; runtime components and optional models retain their own licenses.
