Build on Windows x64 with .NET Framework 4.8:
  powershell -NoProfile -ExecutionPolicy Bypass -File setup-runtime.ps1
  powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

setup-runtime.ps1 downloads the pinned upstream llama.cpp runtime and verifies
its SHA-256. Model weights are neither required for compilation nor supplied.
Run test.ps1 on an interactive desktop for the controlled native self-check.
See README.md and CONTRIBUTING.md for additional tests and packaging.

The Windows compiler, framework and platform components are separately supplied
by Microsoft. This source does not require a private Makro+ build service.
