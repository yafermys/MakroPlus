# Makro+ 3.0.1 - Touchpad shapes fixed

## Fixed

- **Touchpad detection no longer gets stuck.** On Windows, the window toolkit
  registered itself for raw pointer input after Makro+, so the touchpad listener
  never received movement: *Detect touchpad* waited forever and shapes did not
  run. Makro+ now keeps that registration.
- Touchpads that report **absolute positions** (common with Precision
  Touchpads) are read correctly, and touchpads without a device name are
  recognised.
- *Detect touchpad* has a **Cancel** button and gives up after 20 seconds with
  an explanation.

## New

- **Create with AI** can use a **touchpad shape** as the trigger: choose
  *Touchpad shape*, draw it, then describe what should happen.

## Validation

- Unit tests (11): touchpad detection, recording, triggering and timeout; AI
  plans with a touchpad trigger; key capture and matching; settings import.
- Real Raw Input end-to-end test: detection, a shape drawn with relative
  movement and one drawn with absolute movement each ran their shortcut.
- Keyboard end-to-end test with the real hooks: modifier + key, two-key chord,
  modifier + wheel and a switched-off key.
- CI on Windows and Linux.
